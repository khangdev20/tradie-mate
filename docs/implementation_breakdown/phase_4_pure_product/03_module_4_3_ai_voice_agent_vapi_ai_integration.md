## 📌 Module 4.3: AI Voice Agent (Vapi.ai Integration)
**Timeline**: Month 36+
**Focus**: AI-driven phone handler to answer customer calls while the tradie is busy.

### Business Value & Adoption Evaluation

**User intention**: "Answer calls professionally when I cannot pick up."

**Why users will use it**:
*   It captures jobs during work hours, driving, and after-hours.
*   It can replace part of the need for admin staff in small businesses.

**Adoption risk**:
*   Customers may dislike AI if not disclosed clearly.
*   Bad call handling can harm the tradie's brand, not only the app.
*   Voice workflows require strong reliability, latency, and escalation paths.

**Retention mechanism**:
*   If the AI reliably creates paying jobs, TradieMate becomes revenue infrastructure.

**Migration support**:
*   Start as after-hours assistant or missed-call callback before becoming primary call answerer.
*   Let tradies review call scripts, business hours, service areas, and emergency rules.

**Success metrics**:
*   Calls answered.
*   Caller completion rate.
*   Job draft creation rate.
*   Tradie acceptance rate.
*   Customer complaint/escalation rate.
*   Revenue attributed to AI-captured jobs.

**Build detail additions**:
*   Add script configuration per tradie: greeting, service areas, unavailable services, emergency disclaimers.
*   Add human handoff/fallback SMS.
*   Store consent/disclosure events and call summaries.

### 📱 Mobile UX & UI Specifications (React Native)

> **Design System Instruction**: Implement this UI using `TradieMate_Design_System.html` v1.0 tokens: light mode only, base `#FAFAF8`, elevated cards `#FFFFFF`, CTA `#2E6B45`, semantic success/warning/danger/info colors, Inter typography, 4px spacing scale, `8px` element radius, `12px` card radius, minimum `44px` touch targets, `0.5px` borders, no shadows, no gradients, and MaterialCommunityIcons with explicit size/color, preferring library icons over typed text symbols for actions and statuses. This supersedes any older orange CTA, thick-border, or hard-shadow wording in the detailed bullets below. Build this UI from shared primitives in `packages/ui` (`AppButton`, `IconButton`, `AppCard`, `StatusBadge`, `EmptyState`, `FormField`, `Stepper`, `SwipeConfirm`, `ModalShell`, `MapPanel`) before creating module-local components.

#### 🎙️ Voice Agent Log View
*   **Voice Waveform Interaction**:
    *   When reviewing call recordings generated by the AI voice agent, display an interactive waveform player.
    *   Render waveforms using bold, vertical bars with a `1px` black outline. As the recording plays, animate the waveform bar colors from gray to Forest Green CTA (`#2E6B45`).
    *   Allow users to tap anywhere along the waveform to skip directly to that segment of the recording.

### 🔌 API & Database Specification

#### 🛣️ Endpoints Details

##### 1. `POST /api/v1/integrations/vapi/webhook`
*   **Auth**: Vapi Webhook Secret Validation check.
*   **Request Body**:
    ```json
    {
      "message": {
        "call": {
          "customer": { "number": "+61412345678" }
        },
        "analysis": {
          "structuredData": {
            "customerName": "Jane Smith",
            "address": "42 Queen St, Brisbane",
            "jobDescription": "Blocked sewer main drains",
            "urgency": "Urgent"
          }
        }
      }
    }
    ```
*   **Business Logic**:
    *   Decode payload, retrieve corresponding `tradie_id` using forwarded number records.
    *   Create a job draft record with status `'PENDING'` (Draft state).
    *   Dispatch push notifications alerts to the target tradie app.
*   **Response (`200 OK`)**:
    ```json
    {
      "success": true,
      "data": {
        "success": true
      }
    }
    ```
*   **Workflow Evaluation**:
    *   **Pre-conditions**: Valid Vapi signature validation secret configured.
    *   **Test Request**:
        ```bash
        curl -X POST -H "X-Vapi-Secret: mock_vapi_secret" \
          -H "Content-Type: application/json" \
          -d '{"message": {"call": {"customer": {"number": "+61412345678"}}, "analysis": {"structuredData": {"customerName": "Jane Smith", "address": "42 Queen St, Brisbane", "jobDescription": "Blocked sewer main drains", "urgency": "Urgent"}}}}' \
          "http://localhost:3000/api/v1/integrations/vapi/webhook"
        ```
    *   **Expected Assertions**:
        *   **HTTP Status**: `200 OK`
        *   **Response**: Standardized envelope with `success: true` and integration response inside `data`.
        *   **Database Validation**: Inserts a new draft job in `jobs` table with status `'PENDING'`.
        *   **Side Effects**: Dispatches push notification warning the matched tradie of a new voice lead.
