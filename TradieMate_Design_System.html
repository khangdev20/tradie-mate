Design rules
Không phá vỡ bất kỳ rule nào dưới đây.
NEVER
Drop shadows — không box-shadow trên bất kỳ component nào
Gradients — không linear/radial-gradient cho UI
Font weight 700 — max là 500 cho heading
Touch target dưới 44px — tradies đeo găng
Emoji / unicode icons trong UI — chỉ dùng MaterialCommunityIcons
Border width trên 0.5px
ALWAYS
Background #FAFAF8 — không pure white #FFFFFF cho base
Offline indicator luôn visible trên Dashboard
"Next job" card phải là element lớn nhất Dashboard
"Slide to start" cho critical irreversible actions
GST line rõ ràng trên invoice — bắt buộc luật Úc
Pass size + color rõ ràng cho mọi Icon component
